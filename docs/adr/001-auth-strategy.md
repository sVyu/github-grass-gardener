# ADR 001: 웹 MVP의 PAT 메모리 인증

- 상태: 채택
- 맥락: 브라우저에서 GitHub 계정 및 저장소 API에 접근해야 한다. MVP에는 인증 서버가 없다.
- 결정: 사용자가 PAT를 입력하고, 런타임 메모리에만 보관한다. 연결 해제 또는 새로고침으로 폐기한다. 이메일 API가 권한 부족으로 거부되면 사용자 ID 기반 `noreply` 주소로 대체한다.
- 결과: 로컬 실험을 빠르게 시작할 수 있지만 매 세션에 다시 연결해야 한다. 브라우저 XSS가 실행되는 동안 토큰 탈취를 완전히 방지하지는 못한다. 공개 배포 전에 GitHub App 또는 OAuth/BFF 설계가 필요하다.
